# Riyadus Salihin — Terjemahan Melayu

Draf terjemahan Melayu bagi *Riyadh as-Salihin* karya Imam an-Nawawi, diterjemah daripada teks Arab dengan bantuan AI.

> **Draf, belum disemak.** Terjemahan Melayu, baris (harakat) pada teks Arab dan penandaan sabda/perbuatan Nabi ﷺ dibuat oleh AI dan perlu disemak oleh ahli ilmu sebelum dijadikan rujukan. Teks ayat al-Quran diambil daripada teks Uthmani (Hafs) dan terjemahan Kemenag melalui quran.com.

**Baca dalam pelayar:** https://kassimkot.github.io/riyadus-salihin-melayu/

**Aplikasi Android:** [riyadus-salihin.apk](https://kassimkot.github.io/riyadus-salihin-melayu/riyadus-salihin.apk)

## Memasang aplikasi Android
1. Buka pautan APK di atas pada telefon dan muat turun.
2. Buka fail itu. Jika diminta, benarkan "Pasang aplikasi tidak diketahui" untuk pelayar atau pengurus fail anda.
3. Tekan **Pasang**.

Aplikasi berfungsi tanpa internet. Setiap kali dibuka, ia menyemak kandungan baharu di laman ini dan mengemas kini dirinya secara automatik.

## Kandungan repo
- `index.html`, `app.html` — pembaca (satu fail lengkap).
- `version.json` — nombor versi yang disemak oleh aplikasi.
- `riyadus-salihin.apk` — aplikasi Android.
- `sumber/` — data terjemahan dan skrip binaan.
